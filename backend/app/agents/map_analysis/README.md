# 카카오맵 조회·일치 규칙

단일 decision의 지도 도구가 주변 업종·시설을 확인할 때 쓰는 비동기 클라이언트와 코드 규칙입니다.
도구 연결과 fact 등록은 `app/agentic/map_regulation.py`, 이 폴더에는
[client.py](client.py), [config.py](config.py), [matching.py](matching.py)를 둡니다.

카카오 장소 원문을 보존하고, 분류·업종 검색어로 `category_match`, `name_match`, `unknown`을 구분합니다.
LLM으로 장소를 매핑하지 않습니다. 규칙 일치는 실제 경쟁점이나 입점 가능성의 확정 판정이 아닙니다.
시설 조회는 시설 분류와 검증된 거리를 사용하며 업종 검색에서는 공통 업종 코드와 검색 표현을 검증합니다.

지도 결과는 조회 시점의 등록 표본입니다. 분기 CSV 점포 수·폐업률 분모에 더하지 않습니다.
검색 영은 등록 누락이나 범위 한계일 수 있으며 실제 점포·시설 부재로 확정하지 않습니다.
최근접은 반환된 유효 표본 안의 거리이며 도보 시간으로 환산하지 않습니다.

설정은 주소 변환과 같은 `GEOCODING_API_KEY`와 동시 수 상한 `MAP_ANALYSIS_MAX_CONCURRENCY`입니다.
키와 외부 오류 원문은 저장하지 않으며 API 실패와 정상 영을 구분합니다.
규제 조회는 별도 교육환경보호구역 자료를 사용합니다.

공개 실행·대역 검사·질문 재개는 [백엔드 README](../../../README.md)와
[API 계약](../../../../docs/API_CONTRACT.md)을 따릅니다.
