## 원본과 생성물

- `data/industries.csv`: 서비스 51개. `source_middle_codes`는 원래 중분류이며 합병 출처를 보존합니다.
- `data/small_to_industry.csv`: G213·G215의 9개 소분류를 명시합니다. 소분류 코드·이름은 저장소의 `examples/schema_compare/upjong_small_official.csv`에 있는 2023-02-28 자료로 확인했습니다.
- `data/seoul_to_industry.csv`: 기존 99개 행을 보존하고 90개만 연결합니다. 제외 9개는 빈 코드와 사유를 남깁니다.
- `data/legacy70_to_industry.csv`: 과거 70업종의 연결표입니다. 제외 항목은 빈 코드, 합병으로 중복된 연결은 하나만 남깁니다. 과거 점수를 복제하거나 평균하지 않습니다.
- `data/industry_profile.csv`: 51개 업종의 기존 시간대는 `reviewed=true`, 새 D2·D3·C4 열은 사용자 결정에 따라 51행 모두 `reviewed_v2=true`로 승인됐습니다. 서비스에서는 아직 읽지 않습니다.
- `catalog.py`: 위 네 분류 CSV에서 생성합니다. 생성물을 직접 수정하지 않습니다. CSV는 UTF-8 BOM 형식입니다.

```powershell
cd backend
python scripts/build_industry_catalog.py
python scripts/build_industry_catalog.py --check
```

`build_upjong_master.py`와 `build_industry_links.py`는 이전 75개 원천 체계 수집기입니다. 서비스 마스터를 덮어쓰지 않도록 차단했습니다. 변경은 검토된 CSV와 카탈로그 생성기를 사용합니다.

## 매핑과 집계

`lookup.service_code(middle_code, small_code)`가 소분류를 먼저 적용합니다. G213·G215에 소분류가 없거나 알 수 없으면 중분류 전체를 임의 배분하지 않습니다. 음반/비디오물 G21303은 목표 범위에서 제외합니다. 나머지 중분류는 합병 출처를 서비스 코드로 연결합니다.

상권의 요청 반경·비교 반경·자치구·반경별 순위·대분류·프랜차이즈 집계는 `map_stores()`를 거친 점포만 사용합니다. 미매핑 점포는 집계 분모에서도 제외하고 경고에 건수를 남깁니다. 원천 캐시는 그대로 두고 읽은 점포를 변환합니다.

개폐업은 서울 원천 코드의 점포·개업·폐업 건수를 서비스 업종별로 먼저 합산하고 비율과 상대 점수를 다시 계산합니다. 상권·분기 응답이 존재하면 누락 원천의 세 건수를 0으로 처리하며 `zero_filled_sources`에 분기×원천 보충 건수를 남깁니다. 상권·분기 응답 자체가 없거나 실제 반환 필드가 null이면 결측을 유지합니다. 원천 전체가 없는 업종은 비율 None·missing 상태를 유지하고, 서울시 미지원 6개 업종은 unavailable/unsupported로 보존합니다.

지도 설명은 새 서비스 명칭과 검증된 소분류를 사용합니다. 교육 카카오 분류는 P105, 의원 분류는 Q102에 적용합니다. 서비스 명칭 변경은 현재 카탈로그를 반환하는 코드 경로에 반영되며 과거 저장 결과를 자동 변환하지 않습니다.

## LQ와 밀도 기준선

- 합병 업종은 지역·주변·자치구 점포 원자료를 동일한 서비스 코드로 합쳐 LQ를 다시 계산합니다. 기존 LQ나 백분위 값을 합산하지 않습니다.
- 분할 원자료에 소분류가 없으면 G203/G213 또는 G215/G215B의 해당 LQ를 null 및 `citable=false`로 표시합니다. 반경·자치구 특화 순위에서도 제외합니다. 보완 조회도 기존 차단을 우회하지 않습니다.
- `build_density_baseline.py`의 기존 산출물은 업종별 LQ 기준선이 아니라 **음식점 전체 밀도 분포**입니다. 음식점 소스 범위가 유지되므로 기존 상수는 보존합니다. 이후 생성도 같은 서비스 매핑으로 음식점을 셉니다.
- 복합·분할 업종의 점포 수를 기존 중분류별 백분위에서 복원하지 않습니다. 공공 API 재수집은 하지 않았습니다.

옛 실행용 목업·색인·파이프라인 테스트는 삭제했습니다. 현재 소분류 분할·제외 회귀는
`tests/test_industry_51_mapping.py`에서 확인합니다. 실제 원자료는 분기 자료 DB에 보존하고,
근거 CSV `examples/schema_compare/upjong_small_official.csv`는 카탈로그 생성 검증에 계속 씁니다.

- C1 51업종 밀도 기준선은 `scripts/build_density_baseline.py --industries --seoul-csv <저장소 밖 서울 CSV> --quarter <YYYYQ>`로 준비합니다. 공공데이터포털 「소상공인시장진흥공단_상가(상권)정보」의 서울 UTF-8 파일을 사용하며 API를 호출하지 않습니다. 1,650개 중심·500m·개/km²는 기존 방식과 같습니다. 출력 주석에 파일 기준 분기를 남기며 원문·계산 표본을 커밋하지 않습니다.
