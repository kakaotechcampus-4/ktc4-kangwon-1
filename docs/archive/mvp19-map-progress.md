## 최종 검증

- 독립 리뷰에서 외부 입력 경계 3건 발견. 각각 실패 테스트로 재현한 뒤 수정하고 재검증했다.
  - 잘못된 장소 하나가 전체 조회를 중단하지 않도록 해당 장소만 제외하고 `partial`·주의사항을 남긴다.
  - 원본 분류가 없는 장소는 LLM 매핑에서 제외하고 `unmapped`로 보존한다.
  - 중복 JSON 키가 덮어써지지 않도록 공통 LLM 파서에서 거절한다. 이 검증은 기존 분석 LLM 호출에도 적용되며 유효한 JSON 계약은 유지한다.
- Python 3.12.14: 백엔드 `unittest` 449개, 검증 도구 26개 통과.
- 백엔드·검증 도구 Ruff 통과, 변경 코드 포맷 통과, mypy 78개 소스 통과.
- 질문 대기 후 별도 프로세스에서 답변·재개하는 검사와 지도 저장 직후 취소 시 관측 보존 검사를 포함했다.
- 실제 카카오 응답 품질·LLM 매핑 정확성·지연시간은 검증하지 않았다. HTTP API·프론트 연결과 중단된 조회 자동 복구는 이번 범위에서 제외했다.
- `validation_tool` 변경은 기존 Git 제외 상태를 유지한다. 공유하려면 별도 포함 여부를 결정해야 한다.
- 커밋·푸시 없이 현재 브랜치에 보존했다.

## 정식 API·임시 검증 화면 연결 (2026-09-29)

- 정식 분석 요청에 반경·지도·질문 허용을 연결하고, 답변 제출·재개와 질문/분석/보완/지도 조회를 추가했다. 기존 주소만 받는 동기 응답 계약은 유지한다.
- `validation_tool.web`은 같은 정식 API를 호출한다. 상세 trace만 의존성 주입으로 감싸고, 테스트 DB는 기존 서비스 DB와 분리한다.
- API 경계 테스트를 먼저 실패시킨 뒤 구현했다. 대역 지도→질문→답변/건너뛰기→최종 결과를 실제 브라우저에서도 확인했다.
- 독립 리뷰의 답변 동시 제출 충돌(500→409), 강제 목업 환경에서 실제 모드 오표시를 각각 실패 테스트로 재현하고 수정했다.
- 최종 확인: 백엔드 455개, validation_tool 27개 통과. Ruff·포맷·mypy 79개 소스 통과.
- 범위 결정: 기존 지도 통합 자체의 재리뷰, 추천 품질, 실 API·LLM 연결은 이번 검증에서 제외. 공개 배포 인증·권한은 미구현으로 계약 문서에 명시. 임시 서버 재시작 뒤 작업 목록 복원은 추가하지 않았다.
- 프론트엔드 폴더·분석 에이전트 원본은 변경하지 않았다. 커밋·푸시 없음. 임시 화면은 기존 Git 제외 상태를 유지한다.
