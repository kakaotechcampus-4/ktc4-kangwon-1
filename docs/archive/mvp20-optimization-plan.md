> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 임대인에게 나가는 숫자와 근거를 바로잡고, 필요 없는 LLM 호출·중복 코드·우회 경로를 걷어 내 분석 1회의 비용·지연·실패 지점을 줄인다.

## 3단계. 분석 에이전트 내부 LLM 정리

세 에이전트 모두 LLM이 라벨·요약·선별만 한다. 수치는 코드가 이미 만들고, 최종 문장은 최종판단이 쓴다.

- [x] **개폐업:** 건수 우위로 유형·설명을 생성하고 기존 수치·점수를 보존한다. 배치 모델·프롬프트·설정 주입·직접 모델 테스트를 제거했다. 기존 파이프라인 오류 유형은 agent.py로 옮겨 유지한다.
- [x] **상권:** `summarize`를 제거하고 기존 요약 구조에 계산된 반경·점포 수를 제공한다.
  - 요약 모델·프롬프트·응답 파서·분석용 모델 설정을 제거했다. 기존 `summary` 구조에 반경·조회 점포 수를 채우고 표시 함수만 `summary.py`에 남긴다. 업종 매핑 예제는 별도 `LLMSettings`를 사용한다.
- [x] **인구:** 규칙 선별을 `selection.py`로 옮기고 모델·프롬프트·실행 설정을 제거했다. 저장 해석은 보존하고 복사본에서만 필터링한다. 명시적 선별 함수 주입은 유지하되 넓은 예외 처리를 RuntimeError·ValueError로 좁혀 구현 오류를 숨기지 않는다.
- [x] **지도:** 유효한 매핑을 재사용하고 새 분류만 모델에 요청한다. 일반 매핑 실패 시 원본 장소·기존 매핑을 유지하며 넓은 예외 처리를 좁혔다.
  - 검증된 mapped 결과를 로컬 SQLite 캐시로 7일 재사용한다. 사람 검수 완료표는 아니다. 새 분류 실패 시 기존 캐시는 유지한다. 원본 분류·모델·프롬프트·업종표 변경 시 재조회하며 일반 매핑 오류만 수집한다. 실제 호출 절감량은 아직 측정하지 않았다.
- [x] 분석 3종의 이전 `llm.py`·`prompt.md`·설정·폐기 경로 테스트를 정리했다. 대역 통합 검사로 공통 출력 구조를 확인했다. 지도 매핑·최종판단 모델은 유지한다. 오케스트레이터 모델은 4단계에서 제거했다.
