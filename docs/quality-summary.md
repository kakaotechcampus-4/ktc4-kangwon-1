## 실패를 분석해 바꾼 사례

- 숫자 식별자 거절: [숫자 검사 수정](identifier-live-report.md). 업종 코드·fact 별칭과 측정 숫자를 구분하며 측정 숫자의 자유 표기는 계속 거절한다.
- 지적 근거 상한 3→5·행별 수정: [간소화 입력 기록](simple-l-live-report.md). 빈 근거를 허용한 것이 아니라 제한 안에서 근거를 표현하게 했다.
- 별칭 동시 생성 충돌: [동시성 회귀](alias-concurrency-live-report.md). 기존 별칭 재조회·유한 재시도·트랜잭션으로 검증했다.
- founder 패킷 상한: [상한 전후 대조](founder-live-report.md). 공통 메타데이터를 묶고 공간→지속성→경쟁 우선순위로 값을 보존했다. 새 초안에서는 경쟁 값이 생략돼 추가 조회로 복원됐으며 생략 0건을 일반화하지 않는다.

## 재현 방법과 자료 제약

명령은 `backend/`에서 실행한다. 아래 실자료 명령은 안내이며 이번 작업에서는 실행하지 않았다.

| 대상 | 위치·명령 | 필요한 자료·주의 |
| --- | --- | --- |
| 8주소 × 51업종 = 408건 | `python scripts/verify_rubric_reproduction.py --samples cache/rubric_samples` | sample-*.json 8개와 dryrun-results.json 필요. cache는 Git 제외다. 당시 규칙의 회귀 비교이며 현재 채점 개정 후 동일함을 보장하지 않는다 |
| 코드 채점 백테스트 | `python -m backtest.run --help` | input·data·baselines·out 경로 필요. 주소·시설·규제 외부 호출이 가능하므로 별도 승인 후 실행 |

| 채점·평가표 3종 | [decision 채점표](decision-prompt-rubric.md), [심사관](examiner-evaluator-rubric.md), [임차인](founder-evaluator-rubric.md) | 문서의 역할 범위와 실제 전용 패킷·연결 상태를 함께 확인. 임대인은 별도 평가표 문서 대신 [입력 보강 기록](landlord-context-live-report.md)과 `app/agentic/landlord.py`를 참고 |
