## 공통 공간 사실

업종별 space_fit 사실 한 개(총 51개)에 층·면적·주방·배기·급배수 비교를 넣는다.
비교 값은 일치/불일치/해당 없음/미확인이다. profile fact와 임대인 답변 fact의 ID를 계보로 저장한다.
같은 비교는 같은 ID를 재사용하고 답변으로 값이 바뀌면 새 ID와 현재 비교 포인터를 만든다.

| 조건 | 처리 |
| --- | --- |
| 프로필 요건 false | 해당 없음. 새 불리 요인으로 쓰지 못함 |
| 사용자 답변 없음 | 비교 미확인, L에 쓸 관측 근거 없음 |
| 프로필 conditional·불명확 | 미확인, 조건과 초안 confidence를 표시 |
| 층/면적 | 프로필에 명시된 층·수치 범위와 확인된 답변만 비교. 문자 설명에서 수치 기준을 추측하지 않음 |
| 급배수 | 현재 CSV에 명시된 요구가 없으면 미확인. 임의로 필수/불필요를 채우지 않음 |
| 초안 | reviewed=false·confidence=low 그대로 표시. 비교는 운영 가설과 답변의 대조이며 법규/확정 요건이 아님 |
| L 근거 | 비교 결과 중 확인된 일치/불일치가 있을 때만 인용 가능. 해당 없음만으로 가점/감점 불가 |

원문 셀·집계 계보는 유지하고 fact 간 부모 링크를 추가한다. 이전 미확인 값을 갱신하지 않는다.
space_fit를 L 요인으로 쓰면 space_fit_component로 대상 항목을 명시한다.
유리는 일치·불리는 불일치일 때만 허용하고 해당 없음/미확인은 요인으로 세지 않는다.
get_facts는 source+metrics로 현재 공간 비교 51개를 묶음 조회할 수 있게 한다.
업종 단일 필터와 fact_ids 조회도 유지하고, 공통 근거 조회는 현재 포인터만 반환한다.
도구 응답은 불필요한 반복 메타데이터를 줄이되 fact ID·비교 상태·초안 표시를 보존한다.

## 역할 예산

기존 바깥 안전선 입력400k/출력60k/40회/600초, 호출 출력16k는 유지한다.
역할별 자원 예약은 평가자 네 명을 보장하는 격리 규칙이므로 측정에서도 유지한다.
측정 모드는 바깥 안전선 안의 호출을 녹화하며 임의의 과거 역할 상한은 사용하지 않는다.
역할 시간은 병렬 실행이므로 나누지 않고 공통 600초 마감·모델별 timeout을 따른다.

## 구현 단위

1. 계약·L 단계: contracts/schemas/API 예시·read_tools·report·runtime·tools. 먼저 분할·중복·순서·숫자/업종/요인 검증 회귀를 쓰고 구현한다.
2. 공간 근거: space.py + facts 부모 계보 + 질문 저장·초기 요청 연결. 가짜 프로필·무답변·요건 없음·51개·계보 불변을 검증한다.
3. 역할 예산·평가: budget/evaluators/tools와 프롬프트. 네 역할 동시 실행·quota 고립·읽기 노출·실패 슬롯·재개 누적을 검증한다.

각 단위는 네트워크 없는 모델 대역·녹화 회귀로 검증하고 전체 게이트가 통과한 뒤 구현 커밋 1~3개로 기록한다.
코드90점 산식은 바꾸지 않는다. all-L unknown 408건은 9/1/377/21로 일치해야 한다.
기존 녹화의 결합 제출을 새 계약으로 재해석하지 않는다. 새 계약용 대역 녹화로 재생 회귀를 만든다.

## 실테스트

모든 게이트 통과 뒤 홍대 주소 공개 API 한 요청만 실행하고 질문 시험 답변으로 재개한다.
새 요청 DB·새 녹화 폴더를 사용한다. 이전 원문/녹화/결과를 덮어쓰지 않는다.
DecisionResult·L51개+unknown 이유·공통근거51·후보 상한 위반0·평가자완료4·피드백1·소매 설비 부재 감점없음을 확인한다.
품질 미달이면 수정·재실행하지 않고 원인만 기록한다. .env/규제/자료DB/프론트는 수정하지 않는다.
push하지 않는다. 실측×1.5는 문서 제안만 하고 운영에 적용하지 않는다.
